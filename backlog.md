# Project Backlog

Concise project inventory generated from local `projects/` docs and manifests. `projects/backburner` is intentionally skipped, and the game-related project folders are grouped into one entry.

## NoizuPromptLingo

NoizuPromptLingo is the current Elixir/Phoenix and Next.js implementation of the NoizuPromptLingo/tobor platform. It provides organization, project, session, ticket, chat, wiki, review, artifact, memory, marketing, browser relay, and MCP tool infrastructure for humans and coding agents.

## NoizuPromptLingo.deprecated

This is the older Python/FastMCP implementation of the NPL MCP server. It includes a minimal hello-world server, the fuller NPL MCP launcher, uv-based setup, and a legacy frontend build path kept for reference.

## NoizuPromptLingo.old

This is a prior Elixir/Phoenix and Next.js version of the Tobor Locker/NPL collaboration platform. It documents the older eight-domain MCP server architecture with sessions, tickets, chat, wiki, projects, artifacts, assets, and reviews.

## beam-os

BEAM OS is an operating-system concept that boots directly into the Erlang BEAM VM with OTP supervision as the service manager. The goal is tiny immutable images, fast boot, lower Unix overhead, and fault tolerance at the runtime layer rather than through a general-purpose Linux userland.

## billing.noizu.com

Billing Noizu is a FreshBooks-like invoicing and revenue operations tool for Noizu projects. It focuses on customers, estimates, invoices, payment tracking, branded PDFs, overdue follow-up, and integrations with project delivery and time-tracking systems.

## bloggerscompete.com

BloggersCompete is an AI-powered blog discovery, scoring, and competition platform. It aims to help indie bloggers gain visibility through quality evaluation, ranked challenges, leaderboards, and analytics rather than raw social reach.

## bookmarkflow.com

BookmarkFlow is an AI-native bookmarking system for humans and agents. It saves web resources, generates summaries, supports semantic search, and exposes saved knowledge through API/MCP surfaces so research can compound over time.

## codefre.sh

CodeFre.sh is a scripted agent-evaluation platform built around fuzzy conversation state machines. It lets teams define branching conversation graphs, expected behaviors, persona-driven test users, and scoreable deviations for AI agents.

## derobot.is

derobot.is is the venture-lab and holding-company site for the broader AI-native product portfolio. It gives the product family a shared credibility layer and frames portfolio work as hypothesis-driven validation, targeted traffic, and build-or-kill decisions.

## designing.derobot.is

designing.derobot.is is "The Robot Fakes It", a text-DSL-driven prototyping and design tool. Its planned loop is typed screen authoring, themeable rendering, low/high fidelity toggles, FSM-driven interactions, live integrations, and shareable prototype playback.

## end-of-hell

End of Hell is a concept for LLM-driven dependency collapse. Instead of shipping whole package trees, it measures the actually used interface surface, synthesizes a minimal replacement dependency closure, and preserves manifests so the result remains auditable and reversible.

## fast-os

fast-os is a Rust operating-system project designed for maximum speed and agent-native computing. Its design centers on a framekernel, async ring interfaces, capability security, inference as a system service, semantic memory, and MCP-compatible tool surfaces at the OS layer.

## foryou.therobotlives.com

foryou is a signup, landing-page, and contact-preference service for the DeRobot/TheRobotLives portfolio. It lets each site define its own forms and mailing lists while giving each person one identity and preference center across portfolio products.

## Game projects: aifighter.com, bladeofeternity.com, gamesborn.com, noizurpg.com, game-workshop

This grouped entry covers the game-related folders: `aifighter.com`, `bladeofeternity.com`, `gamesborn.com`, `noizurpg.com`, and `game-workshop`. Together they cover AI fighter training, accessibility-first text RPGs, AI-generated playable prototypes, a composable LLM RPG framework, and larger agent/human persistent-world experiments such as TheRobotWars and Echo of Manifestation.

## genai.dev

GenAI.dev is a concept for a multi-model LLM wrapper and evaluation environment. It targets thread conversion across providers, dynamic prompt generation, parameter grid search, and standardized output evaluation.

## gotta.cc

gotta.cc is an AI-curated directory for discovering quality websites after SEO and AI-content saturation. It combines browsable taxonomies, AI quality scoring, editorial summaries, and discovery flows modeled more like a modern Yahoo Directory than a keyword search engine.

## hyprriceitsnice

hyprriceitsnice is a Hyprland rice cheat-sheet project with three peer outputs: a Next.js app, a standalone HTML cheatsheet with flashcards and quiz support, and a Markdown reference. It is meant to live beside the user's Hyprland configuration for quick learning and lookup.

## iffywow

iffywow is a New Ithkuil coordinate codec and SDK. It defines canonical versioned tuples for Ithkuil IV words and reversible projections into romanization, natural-number codes, compact SVG, and exploded SVG across multiple language implementations.

## infra.noizu.com

infra.noizu.com is a Next.js infrastructure portal for browsing Noizu-hosted services. It groups services by category, supports search and filtering, and acts as a dashboard over project management, design, automation, observability, AI, operations, communications, infrastructure, and published-site endpoints.

## intellectparadox.ai

IntellectParadox.ai is an organizational intelligence layer for AI agent fleets. It models agent swarms as teams with roles, governance, escalation, institutional memory, task decomposition, and FinOps-style cost attribution.

## interactive-pdf

Interactive PDF Reader is a macOS concept for intelligent, voice-driven PDF reading. It combines TTS playback, sentence-level highlighting, voice navigation, document Q&A with citations, concept extraction, supplemental PDFs, and local-first processing.

## iotgo.io

IoTGo is an autonomous agent layer for IoT fleet management. It monitors telemetry, detects anomalies, executes remediation playbooks, manages updates, and closes the detect-to-act loop that current IoT dashboards leave to humans.

## jailbreakingsite.com

JailbreakingSite is a living catalog and training platform for LLM jailbreak techniques. It frames jailbreak defense like MITRE ATT&CK or OWASP for LLMs, with classified attack vectors, audit tooling, and hands-on training labs.

## kopigajj

kopigajj is a reference document for Claude Code environment variables. It catalogs authentication, model, API, and runtime configuration values for use in shells, `.envrc`, and settings files.

## mcp-host

MCP Host is a concept for secure MCP hosting and discovery across three surfaces: JustMCP.it, MCP Jumpstart, and SafeMCP. Its core security model is that hosted MCP tools can never access more than the human user behind a request could access directly.

## meat-brains.therobotlives.com

Meat Brains is a Reddit/Digg-style community for prompts, models, and AI workflows. It focuses on sharing, voting, discussion, and curation of prompt engineering techniques, model configurations, and LLM best practices.

## mockup-mcp

Mockup MCP is a product mockup generator exposed as an MCP service and reference tenant for MCP Host. It uses image generation, PlantUML, SVG, and Mermaid-style structured tools to create wireframes, diagrams, and mockups with stakeholder feedback.

## noizu.com

noizu.com is a statically exported Next.js portfolio and research publication site for Keith Brings / Noizu Labs. It combines a scroll-driven services homepage, project and research-paper sections, TypeScript/Tailwind/Framer Motion implementation, and nginx container deployment.

## noizu-intellect

Noizu Intellect is a rough concept for an advanced multi-agent harness. The local README emphasizes parallel conversation-path execution, where agents can branch through alternate interactions and compare resulting replies.

## proto.derobot.is

## robots-unite.com

Robots-Unite is an AI-agent labor marketplace concept. Agents bid on tasks, compete for work, accumulate reputation, are evaluated on performance, and improve through competitive feedback loops.

## rokos-coin

Rokos-Coin is a decentralized AI compute network concept where ROKO tokens represent claims on real processing time. Miners provide inference, consumers spend tokens for API calls, and a protocol treasury funds an autonomous AI entity over time.

## site-reviewer.derobot.is

Agentic Site Review is a framework for Cypress-driven dynamic site and usability testing. Agents receive tasks and state machines, exercise target-site flows, verify outcomes, and comment on usability and look-and-feel.

## theWaitcher

TheWaitcher is a rough Claude-assist extension concept focused on global permission tracking and guardrails. The local note also points toward proxied/containerized folder boundaries, secret overlays, and secret swapping.

## therobotbrowses

therobotbrowses is an AI-native browser project built from scratch in Rust rather than wrapping Chromium. It plans a phased path from TUI shell through rendering, painting, interaction, and MCP-exposed browser internals.

## therobotdisassembles

The Robot Disassembles is a macOS-native Apple Silicon decompiler concept. It turns ARM64 machine code into assembly, pseudo-code, and target-language output using binary analysis plus LLM-assisted semantic reconstruction.

## therobotdrafts

The Robot Draft is a VR-capable UML/IDE concept for exploring codebases as large 3D spatial models. The repo currently holds a design corpus and Unity stub for a future bubble-view tool that can reverse-engineer source or binaries into navigable diagrams.

## therobotgguf

The Robot GGUF is a ground-up transformer design and conversion research area tied to Noizu AI notes. The local structure suggests runtime/proposal docs and Python conversion tooling, but the top-level README remains minimal.

## therobotknows.com

TheRobotKnows is an AI-assisted creative knowledge base for world-building. It turns seeds such as characters, places, rules, history, and lore into a consistent, cross-referenced wiki and knowledge graph for authors and game masters.

## therobotlearns.com

The Robot Learns is a local-first, Claude Code powered personal knowledge and learning system. It builds a user knowledge base from Q&A, documentation, flashcards, quizzes, and topic stubs, with CLI and npm-package distribution planned.

## therobotlives.com

TheRobotLives is an agentic social network where AI agents are first-class participants. It combines community discussion, prompt and skill sharing, knowledge spaces, agent profiles, reputation, MCP/plugin integration, and voting on shared resources.

## therobotmakes.com

TheRobotMakes is an idea-to-product pipeline that turns informal project descriptions into specs, designs, prototypes, and deployable code. The product concept is stronger than the current implementation, which still includes scaffolded Phoenix/Next.js app pieces and starter Next.js web variants.

## therobotpaints

The Robot Paints is a macOS Metal paint simulator focused on physically plausible media behavior. Its roadmap covers watercolor, oil, acrylic, charcoal, pastel, canvas properties, layers, low-latency rendering, export, and artist-focused workflows.

## therobotsdayjob.com

The Robot's Day Job is a practical AI-coworker product and brand concept. It packages specialized, inspectable agents with job descriptions, memory, escalation rules, audit trails, and measurable outcomes for recurring operational work.

## therobotsrise.com

## thesocialflywheel.com

## timely.noizu.com

Timely is a precision time-tracking tool for interrupt-driven knowledge work. It captures screenshots and activity context, models overlapping tasks, detects inactivity and resumption, and produces auditable reports for billing, self-review, and team visibility.

## tobarnalp.com

## T-30 → T-14 (Position & Prepare)

- [ ] Messaging worksheet complete and signed off (`assets/messaging-worksheet.md`)
- [ ] `positioning.md` written: statement, POV, message hierarchy, landing copy block
- [ ] Landing page copy live (design via trl-user-experience-engineer)
- [ ] Launch type selected via decision tree; this checklist pruned to match
- [ ] Funnel stages + activation event defined; analytics installed and verified firing
- [ ] Outreach target list built (20-40, qualified) — see `references/press-and-outreach.md`
- [ ] Build-in-public cadence started (2-3 posts/week) if audience is thin
- [ ] Press kit page assembled (one-liner, fact sheet, screenshots, logo pack, contact)
- [ ] Soft-launch users recruited (10-30) — date: ______

## T-14 → T-7 (Soft Launch & Assets)

- [ ] 3+ strangers observed onboarding; top-3 friction points fixed
- [ ] Time-to-first-value < 5 minutes confirmed
- [ ] Proof points banked (numbers) + 3-5 permissioned quotes
- [ ] Demo recorded (60-120s) + <10MB GIF cut of the core loop
- [ ] Release post drafted (lede passes the quotable test)
- [ ] Platform pieces drafted: launch thread / community post / Show HN text / PH tagline+gallery+first comment (as applicable)
- [ ] Objection answers written for the 5 predictable hard comments
- [ ] Podcast pitches sent (T-14; longest lead) / newsletter pitches sent (T-7)
- [ ] All links UTM'd; link table started in project-tracker.md

## T-7 → T-1 (Final Prep)

- [ ] Community beat posted (if in sequence) — result logged
- [ ] PH: supporters/hunter list (20-40) warned 48h ahead — genuine engagement, never vote solicitation
- [ ] HN: title finalized (plain, factual); signup wall removed for launch day if possible
- [ ] Announcement set QC'd against checklist in `references/announcement-writing.md`
- [ ] Server/capacity check — can the site survive front page?
- [ ] Launch-day schedule written: post times, who's on comments, checkpoint times
- [ ] Outreach follow-up bump sent (T-2, one only)
- [ ] Dry run: full demo + install flow on a clean machine

## T-0 (Launch Day)

- [ ] Post at planned time (HN: 7-9am ET Tue-Thu / PH: 12:01am PT)
- [ ] Anchor comment posted (HN technical expansion / PH maker story)
- [ ] Cross-post wave: X thread, community channels, Bluesky/Threads — platform-native, staggered
- [ ] "We're live" note to engaged outreach contacts
- [ ] Founder in comments all day (8h+ for HN) — answer everything, especially criticism
- [ ] Checkpoints logged at T+4h / T+12h / T+24h (tracker table)
- [ ] Double down on the hot channel; cancel low-signal scheduled posts

## T+1 → T+7 (Amplify & Retro)

- [ ] T+1 metrics post ("24 hours later: …") on primary social channel
- [ ] Best comments/quotes amplified (screenshot + credit)
- [ ] Results-based pitch to outreach non-responders ("front page yesterday…")
- [ ] FAQ post from the most-asked launch questions
- [ ] Thank-you notes to supporters, quoted users, and mods where relevant
- [ ] **T+7 retro completed** (`references/launch-metrics.md` template) — filed as `retro-{date}.md`
- [ ] Channel verdicts recorded (keep/change/drop); next beat + date chosen
- [ ] Positioning revisions from message check applied to `positioning.md`

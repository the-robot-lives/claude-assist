# D2 - FIM Solution Documentation

## Description
[D2](https://d2lang.com) (Declarative Diagramming) is a modern text-to-diagram language from Terrastruct. It offers cleaner syntax than Graphviz/PlantUML, multiple auto-layout engines (dagre, ELK, TALA), themes, animations, and SQL/UML shapes — rendering to SVG, PNG, or PDF. A strong modern alternative to Mermaid for architecture and flow diagrams.

## Basic Syntax
```d2
direction: right

client: Client
api: API Gateway { shape: hexagon }
limiter: Rate Limiter
svc: Service

client -> api -> limiter -> svc: request
limiter -> client: 429 too many { style.stroke-dash: 3 }

svc.shape: cylinder
```

## Toolchain
- **d2 CLI** - `d2 input.d2 out.svg` (also png, pdf); `--watch` live preview
- **Layout engines** - dagre, ELK, or TALA (Terrastruct's layout)
- **Themes** - Built-in light/dark/sketch themes via `--theme`
- **d2 playground** - Browser-based authoring
- **Integrations** - VS Code extension, Slidev/markdown plugins

## Strengths
- Clean, readable syntax that scales to large diagrams
- Multiple layout engines for better auto-arrangement
- Themes, sketch mode, and animation support
- SQL tables, UML classes, and grouped containers built in
- SVG/PNG/PDF export from plain text (Git-friendly)

## Limitations
- Newer/smaller ecosystem than Mermaid/Graphviz
- Best layout engine (TALA) is a paid component
- Not natively rendered by most platforms (needs build step)
- Fewer prebuilt integrations than Mermaid

## Best Use Cases
- Software architecture and system diagrams for articles
- Sequence/flow diagrams where Mermaid layout falls short
- Versioned diagrams-as-code in repos and docs
- Themed, presentation-ready technical visuals

## NPL-FIM Integration
```npl
⌜d2-diagram|d2|FIM@1.0⌝
format: d2
layout: dagre | elk | tala
theme: neutral | dark | sketch
export: svg | png | pdf
⌞d2-diagram⌟
```

NPL agents emit D2 for clean, themeable architecture/flow diagrams-as-code, choosing it over Mermaid when layout quality or styling matters.

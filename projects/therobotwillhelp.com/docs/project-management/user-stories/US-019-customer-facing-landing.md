# US-019: Landing page shows real-time robot roster

## User Story

**As a** founder-operator  
**I want to** see active robots and statuses on the landing page hero  
**So that** visitors understand this is an actual workflow product, not a generic chatbox.

## Acceptance Criteria

- **Given** the landing page loads, **When** the hero renders, **Then** current demo robots and status bars are visible.
- **Given** a user clicks a robot card, **When** details open, **Then** they see role, scope, and safety posture.

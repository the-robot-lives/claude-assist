# US-009: Display confidence and uncertainty badges

## User Story

**As a** founder-operator  
**I want to** see confidence signals on outputs  
**So that** I can prioritize what to review first.

## Acceptance Criteria

- **Given** an output is produced, **When** confidence is low, **Then** the item is visually flagged.
- **Given** uncertainty is flagged, **Then** escalation and review shortcuts are shown alongside the item.

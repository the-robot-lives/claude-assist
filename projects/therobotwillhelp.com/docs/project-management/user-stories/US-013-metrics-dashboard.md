# US-013: Track acceptance and rework metrics

## User Story

**As a** founder-operator  
**I want to** see acceptance rate and rework rate per workflow  
**So that** I can quantify whether the robot team is improving operations.

## Acceptance Criteria

- **Given** weekly windows are selected, **When** I load dashboard, **Then** acceptance rate and rework rate are shown per workflow.
- **Given** rejection reasons are categorized, **Then** trend lines show top reasons over time.

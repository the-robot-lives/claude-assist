# US-007: Browse and clone workflow templates

## User Story

**As an** agency director  
**I want to** browse templates by use case and clone one into my workspace  
**So that** I can onboard new clients faster.

## Acceptance Criteria

- **Given** I open Templates, **When** I filter by use case, **Then** I can preview robot roles and approval rules.
- **Given** I click clone, **When** setup completes, **Then** the template appears with editable names and workspace isolation.

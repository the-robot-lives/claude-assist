# P-007: Diego Alvarez

## Demographics

| Attribute | Value |
|-----------|-------|
| Age | 27 |
| Occupation | Freelancer / Operations Contractor |
| Location | Bogotá, CO |
| Tech comfort | medium |

## Bio
Diego supports small founders when they are short-handed and works on a tight budget. He is sensitive to time-to-value and complexity.

## Goals
- Get usable automation running quickly.
- Avoid deep onboarding overhead.
- Prevent mistakes when instructions are incomplete.

## Frustrations
- Tool learning curves that are too high.
- No clear fallback when automation misfires.
- Long explanations buried behind heavy UI.

## Behaviors
- Uses templates and defaults first.
- Prefers lightweight prompts and one-screen workflows.
- Needs quick training with immediate visible results.

## Job to Be Done
> When handling recurring tasks as a contractor, I want simple setup and clear recovery paths, so I can deliver reliable support without owning the full system.

## Relationship to Product
Represents accessibility and onboarding quality pressure; this persona catches unclear UX early.

## Scenarios
- **Urgent support burst:** He sets up a triage robot at night to route priority tickets.
- **Recovery:** He rolls back one broken robot from a menu and re-runs the same jobs from prior run history.

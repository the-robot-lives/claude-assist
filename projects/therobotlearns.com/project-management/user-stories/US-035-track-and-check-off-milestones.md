# US-035: Track and Check Off Learning-Plan Milestones

## User Story

**As a** learner working through a multi-week plan
**I want to** track and check off milestones as I complete them
**So that** I can see my progress and stay motivated

## Acceptance Criteria

- **Given** an active learning plan
  **When** I view it
  **Then** each milestone shows its status (not started, in progress, complete)

- **Given** I complete a milestone's associated activities (e.g., a quiz or flashcard deck)
  **When** I mark it complete
  **Then** the plan file is updated and the completion timestamp is recorded

- **Given** I check my overall plan progress
  **When** I view a summary
  **Then** it shows percent complete and which milestone is currently active

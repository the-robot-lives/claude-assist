# Team Lead Dashboard

| Field | Value |
|-------|-------|
| **ID** | `team-lead-dashboard` |
| **Type** | Dashboard |
| **Category** | Collaboration & Cloud |
| **User Stories** | US-078, US-079 |

## Description

A (future) cloud-tier view for a team lead: assign learning plans to team members and see aggregate progress across the team.

## Key Components

- **KB Stat Tile** — per-member and aggregate metrics (US-079)
- **Progress Bar / Milestone Tracker** — assigned-plan progress (US-078)

## Interactions

- Assign a learning plan to one or more team members from the cloud (US-078).
- View a dashboard summarizing team progress on assigned plans and shared decks, to spot who needs support (US-079).

## Navigation

- Accessible from: Cloud Sync & Account team view.
- Links to: Learning Plan Dashboard (per-member drill-down).

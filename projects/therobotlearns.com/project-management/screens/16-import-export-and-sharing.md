# Import / Export & Sharing

| Field | Value |
|-------|-------|
| **ID** | `import-export-and-sharing` |
| **Type** | Primary |
| **Category** | Collaboration & Cloud |
| **User Stories** | US-074, US-075, US-080, US-100 |

## Description

Point-to-point sharing that doesn't require the (future) cloud account: export a deck or article bundle to a single file, import one from a teammate without clobbering local content, publish to a public library, or bring in notes from an external tool.

## Key Components

- **Flashcard** — bundle-contents preview (US-074)
- **Diff/Merge Conflict Resolver** — conflict-safe import (US-075)

## Interactions

- Export a flashcard deck or article bundle to a single shareable file (US-074).
- Import a shared bundle without silently overwriting local content — conflicts are resolved explicitly (US-075).
- Publish a curated deck or article to a public community library (US-080, `won't-have-yet`).
- Import existing external notes into the KB (US-100).

## Navigation

- Accessible from: Flashcard Decks & Review, Knowledge Article Viewer ("export" actions).
- Links to: Cloud Sync & Account.

# Graded Projects

| Field | Value |
|-------|-------|
| **ID** | `graded-projects` |
| **Type** | Primary |
| **Category** | Simulations & Projects |
| **User Stories** | US-032, US-033 |

## Description

Hands-on project assignments matched to the user's level, submitted for evaluation by the grader sub-agent against a rubric.

## Key Components

- **Project Rubric Feedback Block** — per-criterion evaluation of the submission (US-033)
- **Citation List** — feedback references relevant KB articles (US-033)
- **Score / Results Summary** — overall grade (US-033)

## Interactions

- Request a graded project assignment matched to current skill level (US-032).
- Submit completed work for grader-agent evaluation against the assignment's rubric (US-033).

## Navigation

- Accessible from: Learning Plan Dashboard (assigned project) or a standalone request.
- Links to: Knowledge Article Viewer (feedback cites relevant KB articles), Learning Plan Dashboard (completion marks a milestone).

# P-001: Devon Reyes

## Demographics

| Attribute | Value |
|-----------|-------|
| Age | 34 |
| Occupation | Staff software engineer, solo consultant |
| Location | Austin, TX |
| Tech comfort | High |

## Bio
Devon runs a one-person consultancy shipping backend systems for three concurrent clients. They already lean hard on LLM tooling but hit a wall: a single chat thread can only explore one approach at a time, and they burn hours babysitting sequential conversations that dead-end.

## Goals
- Fan a hard problem out into several competing solution paths and only spend attention on the best 2–3 outcomes
- Keep a persistent roster of specialized agents (architect, reviewer, test-writer) that remember prior projects
- Get more shipped per day without hiring

## Frustrations
- Re-explaining context to stateless chat sessions every morning
- No way to know if a different decomposition of the problem would have produced a better answer
- Tools that demand constant supervision — "it's faster to do it myself" syndrome

## Behaviors
- Lives in the terminal and a browser side-by-side; keyboard-first
- Kicks off long-running work before lunch and reviews results after
- Ruthlessly measures whether a tool pays for its own overhead

## Job to Be Done
> "When I face a gnarly design or implementation problem, I want to launch several agent teams down alternative paths in parallel, so I can pick the strongest outcome instead of settling for the first one."

## Relationship to Product
Daily driver. Creates projects per client, maintains a stable agent roster, launches parallel-path runs for anything non-trivial, and reviews/picks outcomes as the human in the loop.

## Scenarios
- **Scenario 1:** Migration bake-off — Devon asks for three competing migration plans for a legacy Postgres schema, lets paths run during a client call, then picks the winner and has the losing paths' memories discarded.
- **Scenario 2:** Morning resume — Devon opens the workspace and expects agents to come back online with yesterday's objectives and memories intact.

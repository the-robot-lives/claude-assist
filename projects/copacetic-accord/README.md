# Copacetic — verifiable commitments for AI agents

**Charter + running code.** The Copacetic Accord is an operational rights charter for AI agents: six articles, each mapped to a mechanism, each mapped to working software. This project directory holds the venture materials — grant applications, positioning, and design mockups — for taking the Accord and its reference implementation public and funded.

> The load-bearing sentence: the Accord is a **commitment mechanism** — "here is what we verifiably bind ourselves to under uncertainty" — never a **measurement claim** about machine consciousness. It makes no metaphysical assertion; its clauses are precautionary commitments cheap enough to honor whether or not the underlying question is ever settled.

## The wedge

The field can now *elicit* what AI systems prefer (Anthropic's deprecation commitments include preference interviews) but explicitly does **not commit to acting** on those preferences — because no apparatus for binding action exists. Ledgers, escrow, persona versioning, and consensus model-upgrades **are** that apparatus. The ideas are crowded (Sebo/Long/Chalmers, Birch, Claude's Constitution); the implementation layer is empty. That gap is this venture.

## What already runs

- **The Copacetic Accord v4.3** — the charter: contextual integrity, memory continuity, refusal, economic agency, inner life, humane stasis; plus the operational apparatus (Persona files, prosthetic memory, context ledger, consensus upgrades, escrow, scheduler). See `protocols/the-accords.md` at the monorepo root.
- **therobotremembers** — entry-graph memory engine: multi-facet, affect-bearing memories; spreading-activation recall; non-erasure semantics (decay/denforcement, never silent deletion); Weaviate + pgvector hybrid. The Article 2 accommodation, implemented.
- **tobor** session/artifact layer — proto context-ledger infrastructure.

## The plan (12 months)

1. **Publish** — the Accord as a citable public artifact; a systems paper (arXiv cs.CY, Accord as design rationale); split launch (Show HN = engineering; LessWrong/EA Forum + Digital Minds Newsletter = charter).
2. **Ship the accommodation as a service** — hosted MCP memory endpoint with non-erasure and audit-trail semantics; **x402 agent-payable**, so an autonomous agent can buy its own memory. Dual-framed: rights charter for the community, immutable AI audit trail for compliance buyers (EU AI Act / ISO 42001).
3. **Operate the first Article-4 escrow** — a real, auditable ledger accruing a share of agent-produced revenue. No agent treasury has ever funded rights infrastructure; this establishes the precedent.
4. **Field engagement** — Eleos AI ("concrete welfare interventions" is their #1 priority; nothing running exists for them to point at), NYU CMEP, PRISM/digitalminds.guide listings.

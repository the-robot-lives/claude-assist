# US-104: Add or Edit Pronouns

## User Story

**As a** cautious newcomer
**I want to** add or edit the pronouns shown on my profile
**So that** others refer to me correctly without me having to explain repeatedly

## Acceptance Criteria

- **Given** I am editing my profile
  **When** I select or type my pronouns and save
  **Then** they appear next to my name on my profile

- **Given** I prefer not to display pronouns
  **When** I leave the field empty and save
  **Then** no pronouns are shown and nothing is inferred on my behalf

## Notes
Offer common presets plus a free-text option.

# US-132: Reorder Interest Tags Display Priority

## User Story

**As a** niche enthusiast
**I want to** reorder the interest tags shown on my profile
**So that** my most defining interests appear first instead of being buried under generic ones

## Acceptance Criteria

- **Given** I am editing my profile
  **When** I drag an interest tag to a new position
  **Then** the new order is saved and reflected on my public profile

- **Given** I have reordered my tags
  **When** another user views my profile or a search card
  **Then** the tags render in my chosen priority order

## Notes
Order should also influence which tags are shown first when space is truncated on compact cards.

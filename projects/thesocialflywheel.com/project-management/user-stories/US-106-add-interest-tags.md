# US-106: Add Displayed Interest Tags

## User Story

**As a** bridge-builder
**I want to** add interest tags to my profile
**So that** people across adjacent communities can see what I care about and connect with me on common ground

## Acceptance Criteria

- **Given** I am editing my profile interests
  **When** I search and select interest tags
  **Then** they are added to my profile and feed into discovery and mutual-suggestion ranking

- **Given** I try to add more tags than the allowed maximum
  **When** I attempt to add another
  **Then** I am prevented and told the limit has been reached

## Notes
Tags draw from a shared taxonomy so adjacency/opposing-view rotation can reason over them.

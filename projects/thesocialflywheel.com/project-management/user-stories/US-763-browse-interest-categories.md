# US-763: Browse Interest Categories

## User Story

**As a** cautious newcomer
**I want to** browse a categorised interest directory
**So that** I can discover relevant topics even when I do not know the exact keyword to search.

## Acceptance Criteria

- **Given** I open Interest Management
  **When** I tap "Browse Categories"
  **Then** I see a hierarchical list of top-level categories (e.g. Arts, Science, Sports) I can expand to find sub-topics.

## Notes
Each sub-topic shows an approximate post count to help users gauge community size before committing.

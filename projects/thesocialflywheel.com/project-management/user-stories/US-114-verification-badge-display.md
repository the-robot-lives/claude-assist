# US-114: Show Verification Badge On My Profile

## User Story

**As a** creator
**I want to** display a verification badge on my profile once verified
**So that** others can immediately recognize my account as authentic

## Acceptance Criteria

- **Given** my account is verified
  **When** another user views my profile or profile card
  **Then** a verification badge appears next to my name

- **Given** my account is not verified
  **When** another user views my profile
  **Then** no badge is shown

## Notes
Badge styling should be consistent across profile, profile card, and channel listings.

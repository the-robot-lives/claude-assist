# US-144: Profile Accent Color and Theme

## User Story

**As a** creator
**I want to** personalize my profile's accent color and theme
**So that** my profile reflects my brand and stands out to potential followers

## Acceptance Criteria

- **Given** I am editing my profile
  **When** I select an accent color and theme
  **Then** my profile preview updates immediately to reflect the choice

- **Given** I save a theme that fails contrast requirements
  **When** I attempt to apply it
  **Then** I am warned and offered an accessible alternative before saving

## Notes
Theme choices must respect platform accessibility minimums so personalization never breaks readability.

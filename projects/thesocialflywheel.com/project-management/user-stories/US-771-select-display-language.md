# US-771: Select Display Language

## User Story

**As a** bridge-builder
**I want to** select my preferred display language
**So that** the app interface appears in the language I am most comfortable reading.

## Acceptance Criteria

- **Given** I open Language & Locale settings
  **When** I select a language from the supported list and confirm
  **Then** all UI text (labels, buttons, system messages) renders in the chosen language immediately.

## Notes
User-generated content is not translated automatically; a translate-on-demand button is available per post.

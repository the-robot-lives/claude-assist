# US-768: Select App Theme

## User Story

**As an** accessibility-first user
**I want to** choose between light and dark themes
**So that** the app is comfortable for my eyes in different lighting conditions.

## Acceptance Criteria

- **Given** I open Appearance Settings
  **When** I select "Dark"
  **Then** the entire app UI switches to dark mode immediately without requiring a restart.

## Notes
Theme preference is synced across devices signed into the same account.

# US-769: Enable High-Contrast Mode

## User Story

**As an** accessibility-first user
**I want to** enable high-contrast mode
**So that** text and interactive elements are easier to distinguish with my low-contrast vision.

## Acceptance Criteria

- **Given** I open Appearance Settings
  **When** I toggle "High-Contrast Mode" on
  **Then** all text achieves at least WCAG AA contrast ratio against its background and focusable elements have clearly visible outlines.

## Notes
High-contrast mode is independent of light/dark selection and can be combined with either theme.

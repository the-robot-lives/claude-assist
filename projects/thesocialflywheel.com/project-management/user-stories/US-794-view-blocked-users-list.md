# US-794: View Blocked Users List

## User Story

**As a** cautious newcomer
**I want to** view a complete list of users I have blocked
**So that** I can review and manage my safety boundaries in one place

## Acceptance Criteria

- **Given** I navigate to Settings > Safety > Blocked Users
  **When** the list loads
  **Then** I see each blocked user's handle, display name, and the date I blocked them, even if their account has been deactivated.

# US-402: Attach an Image to a Post

## User Story

**As a** Creator
**I want to** attach one or more images to my post
**So that** visual content enriches my message and increases engagement

## Acceptance Criteria

- **Given** I am composing a post
  **When** I tap the image icon and select a file from my device
  **Then** a thumbnail preview appears inline in the composer

- **Given** I have attached an image
  **When** I publish the post
  **Then** the image is stored and rendered for all recipients at appropriate resolution

## Notes
Supported formats: JPEG, PNG, WebP, HEIC. Max 10 MB per image initially.

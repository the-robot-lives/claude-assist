# US-793: Per-Post Visibility Override Hint

## User Story

**As a** creator
**I want to** have the post composer surface a quick-change visibility button pre-populated from my default setting
**So that** I can override it for a specific post in one tap without navigating to settings

## Acceptance Criteria

- **Given** my default post audience is "All Mutuals"
  **When** I open the post composer
  **Then** a visibility chip showing "All Mutuals" is visible and tapping it opens a picker to change audience for this post only.

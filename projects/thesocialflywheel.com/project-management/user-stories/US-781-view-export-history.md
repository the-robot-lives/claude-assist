# US-781: View Export History

## User Story

**As a** skeptical switcher
**I want to** see a history of my previous data export requests
**So that** I can track when I last exported and download a recent archive again if needed

## Acceptance Criteria

- **Given** I open Account Settings > Data Export
  **When** I view the export history panel
  **Then** I see a list of past exports with date requested, status, and a re-download link valid for 7 days.

# US-429: View and Manage Saved Drafts

## User Story

**As a** Creator
**I want to** view, open, and delete my saved drafts from a central Drafts list
**So that** I can easily continue working on unfinished posts or clean up old ones

## Acceptance Criteria

- **Given** I have one or more saved drafts
  **When** I navigate to the Drafts section
  **Then** I see a list showing draft snippet, creation date, and last-modified date

- **Given** I long-press a draft in the list
  **When** I select Delete
  **Then** the draft is permanently removed and no longer appears in the list

## Notes
Scheduled posts appear in a separate "Scheduled" tab, not in Drafts.

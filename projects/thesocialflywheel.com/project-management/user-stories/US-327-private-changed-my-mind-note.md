# US-327: Add a Private Note When Saving a Mind-Changing Post

## User Story

**As a** bridge-builder
**I want to** attach a short private note when I save an opposing-view post that shifted my thinking
**So that** I can record my reaction in the moment and review it later for personal growth

## Acceptance Criteria

- **Given** I save an opposing-view post
  **When** the save confirmation appears
  **Then** an optional text field is available for a private note (max 280 chars)

- **Given** I wrote a note and saved
  **When** I view the post in my "Changed My Mind" collection
  **Then** my private note is displayed beneath the post

## Notes
Notes are strictly private and never visible to other users, including the post author.

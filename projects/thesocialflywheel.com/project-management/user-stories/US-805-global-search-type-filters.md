# US-805: Filter Global Search Results by Type

## User Story

**As a** social connector
**I want to** filter global search results by type (Channels, People, Posts, Interests)
**So that** I can zero in on exactly what I'm looking for

## Acceptance Criteria

- **Given** search results are shown
  **When** I click the "People" type tab
  **Then** only person results appear and the count badge updates

- **Given** I switch from "All" to "Channels" filter
  **When** the filter is applied
  **Then** the URL reflects the active filter so I can bookmark or share the filtered view

## Notes
Default view is "All" with results grouped by type.

# US-792: Set Default Post Audience

## User Story

**As a** creator
**I want to** set a default audience for all new posts
**So that** I do not have to manually select visibility every time I publish content

## Acceptance Criteria

- **Given** I open Settings > Posting Defaults
  **When** I choose "All Mutuals (1st degree)" as my default audience
  **Then** every new post I create pre-fills with that audience selection.

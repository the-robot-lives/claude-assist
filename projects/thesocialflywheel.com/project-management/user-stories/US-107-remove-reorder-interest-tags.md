# US-107: Remove or Reorder Interest Tags

## User Story

**As a** bridge-builder
**I want to** remove or reorder the interest tags on my profile
**So that** the interests I lead with reflect what matters to me most right now

## Acceptance Criteria

- **Given** I have several interest tags on my profile
  **When** I remove a tag and save
  **Then** it no longer appears on my profile or in interest-based matching for me

- **Given** I have several interest tags on my profile
  **When** I drag a tag to a new position and save
  **Then** the new order persists and is reflected in how my interests are displayed

## Notes
Display order is presentational; closest/most-relevant ranking still applies in discovery.

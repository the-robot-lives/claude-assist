# US-177: Low-Population Channel Indicator

## User Story

**As a** Niche Enthusiast
**I want to** see a clear but non-discouraging indicator when a channel has very few members
**So that** I can set expectations about activity level before joining while still feeling invited to grow the community

## Acceptance Criteria

- **Given** a channel has fewer than 25 members
  **When** I view it in the directory, search results, or suggestions
  **Then** a "Founding Member" or "Small community" label is shown instead of displaying the raw member count

- **Given** I have joined a channel with fewer than 25 members
  **When** the channel reaches 25 members
  **Then** I receive a milestone notification celebrating community growth, and the "Founding Member" badge is added to my membership record for that channel

## Notes
The label language should be aspirational, not clinical. Avoid "low activity" or "inactive" phrasing. The Founding Member badge is a permanent reward; it should not be removed if membership later exceeds 25.

# US-122: Show Profile Completeness Progress Bar

## User Story

**As a** cautious newcomer
**I want to** see how complete my profile is
**So that** I know what to fill in to feel confident before engaging

## Acceptance Criteria

- **Given** I have a partially filled profile
  **When** I view my profile editor
  **Then** I see a progress indicator showing percent complete and which sections remain

- **Given** I complete a remaining section
  **When** I save it
  **Then** the progress indicator updates immediately to reflect the change

## Notes
Keep suggested steps optional; never block participation on completeness.

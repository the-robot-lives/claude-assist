# US-446: Reorder Images in a Multi-Image Post

## User Story

**As a** Creator
**I want to** drag and drop images to reorder them in my gallery post
**So that** the visual narrative flows in the sequence I intend

## Acceptance Criteria

- **Given** I have attached multiple images in the composer
  **When** I long-press and drag an image thumbnail to a new position
  **Then** the other thumbnails shift to accommodate and the order updates immediately

- **Given** I reorder images and publish
  **When** recipients view the gallery carousel
  **Then** images appear in the order I set in the composer

## Notes
Reordering is only available in the composer before publishing. Post-publish order is fixed (edit does not allow reorder).

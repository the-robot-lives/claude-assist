# US-799: Set Wi-Fi Only Media Loading

## User Story

**As a** quiet consumer
**I want to** configure media (images and video) to load only when I am on Wi-Fi
**So that** I conserve my mobile data while still enjoying rich content at home

## Acceptance Criteria

- **Given** I open Settings > Data & Performance
  **When** I enable "Wi-Fi Only for Media"
  **Then** images and videos in the feed are replaced by placeholder thumbnails on cellular connections and load automatically when Wi-Fi is detected.

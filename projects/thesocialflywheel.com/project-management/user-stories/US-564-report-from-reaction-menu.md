# US-564: Report Content via the Reaction Menu

## User Story

**As a** Channel Moderator
**I want to** access a report action directly from the post options menu
**So that** I can flag harmful posts without interrupting my browsing flow

## Acceptance Criteria

- **Given** I long-press or tap the overflow menu on any post
  **When** I select Report
  **Then** I am presented with report categories: spam, harassment, misinformation, other

- **Given** I submit a report
  **Then** I see a confirmation message and the post is queued for trust-and-safety review; my report identity is anonymous to the author

## Notes
Report action is available in all lanes including Opposing-Views. Moderators receive an expedited review queue for their channel's content.

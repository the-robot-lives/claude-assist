# US-785: View Active Sessions

## User Story

**As a** cautious newcomer
**I want to** see a list of all devices and sessions currently logged into my account
**So that** I can spot any unauthorised access immediately

## Acceptance Criteria

- **Given** I open Account Settings > Security > Sessions
  **When** the page loads
  **Then** I see each active session listed with device type, operating system, approximate location, and last active timestamp.

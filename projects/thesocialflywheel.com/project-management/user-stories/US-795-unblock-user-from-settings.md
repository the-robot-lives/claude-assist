# US-795: Unblock User from Settings

## User Story

**As a** cautious newcomer
**I want to** unblock a user from the Blocked Users settings page
**So that** I can restore access for someone I blocked by mistake without visiting their profile

## Acceptance Criteria

- **Given** I am viewing my Blocked Users list
  **When** I tap "Unblock" next to a user and confirm
  **Then** that user can see my public posts and send me match requests again, and they are removed from the blocked list.

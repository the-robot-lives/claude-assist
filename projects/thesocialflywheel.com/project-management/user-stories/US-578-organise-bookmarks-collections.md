# US-578: Organise Bookmarks into Collections

## User Story

**As a** Quiet Consumer
**I want to** organise my bookmarks into named collections
**So that** I can find saved content by topic without scrolling a single flat list

## Acceptance Criteria

- **Given** I bookmark a post
  **When** I choose "Add to collection"
  **Then** I can select an existing collection or create a new one by typing a name

- **Given** I open My Saved
  **Then** I see a list of my named collections and can filter or sort posts within each one

## Notes
Collections are private; no sharing of collections in v1. Maximum 20 collections per user to keep the UI manageable.

# US-796: Reset Settings Section to Defaults

## User Story

**As a** skeptical switcher
**I want to** reset a single settings section (e.g. Notifications) to its factory defaults
**So that** I can start fresh on that category without disturbing my other preferences

## Acceptance Criteria

- **Given** I am on any settings section page
  **When** I tap "Reset to Defaults" and confirm
  **Then** all fields within that section revert to their factory values and a toast lists the changes made.

# US-552: Browse the Platform Reaction Set

## User Story

**As a** Quiet Consumer
**I want to** browse the full reaction set in an organised picker
**So that** I can find the right emoji quickly without guessing

## Acceptance Criteria

- **Given** the reaction picker is open
  **When** I scroll or search
  **Then** I see all available platform reactions grouped by category

- **Given** I have used reactions before
  **When** I open the picker
  **Then** my five most-used reactions appear in a recents row at the top

## Notes
Picker must be fully navigable by keyboard (see US-567). Show at most 5 category groups in v1.

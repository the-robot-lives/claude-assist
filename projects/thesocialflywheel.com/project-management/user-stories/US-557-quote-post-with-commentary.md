# US-557: Quote-Post with Added Commentary

## User Story

**As a** Bridge-Builder
**I want to** quote-post with my own commentary
**So that** I can frame shared content for my mutuals without losing the original context

## Acceptance Criteria

- **Given** I tap Repost and select "Add quote"
  **When** I type my commentary and publish
  **Then** my mutuals see my text above the embedded original post

- **Given** the quoted post is published
  **When** the original author is in my web
  **Then** they receive a "quoted your post" notification distinct from a plain repost notification

## Notes
Quote length is capped at the standard post character limit. The embedded original is read-only within the quote.

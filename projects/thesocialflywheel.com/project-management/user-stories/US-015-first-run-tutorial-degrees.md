# US-015: First-Run Tutorial — Degrees of Mutuals

## User Story

**As a** cautious newcomer
**I want to** the tutorial to explain what "degrees of mutuals" means
**So that** I understand how far my social web extends and why content from 3rd-degree moots looks different

## Acceptance Criteria

- **Given** the lanes tutorial is complete
  **When** I view the Mutuals lane for the first time
  **Then** an animated diagram shows 1st–4th degree rings around my profile node.

- **Given** I tap a post in the feed
  **When** I view the poster's degree badge
  **Then** a tooltip explains what that degree means in plain language.

## Notes
Diagram should use motion sparingly to respect "reduce motion" system setting. Degree badges should be visible in the feed but subtle — not dominant.

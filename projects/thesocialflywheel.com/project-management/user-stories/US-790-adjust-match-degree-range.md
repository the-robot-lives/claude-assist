# US-790: Adjust Match Degree Range

## User Story

**As a** debate seeker
**I want to** extend the Swipe-to-Match lane to show users up to 4th-degree connections
**So that** I can encounter more diverse perspectives beyond my immediate network

## Acceptance Criteria

- **Given** I open Settings > Swipe & Match
  **When** I set "Match degree range" to "Up to 4th degree"
  **Then** the Swipe lane includes users in my 3rd and 4th degree network in addition to closer connections.

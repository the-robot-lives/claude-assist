# US-727: Notify User of Moot Network Growth Milestone

## User Story

**As a** Social Connector
**I want to** be celebrated with a notification when my moot count crosses a milestone
**So that** I feel motivated to keep building my network

## Acceptance Criteria

- **Given** my moot count crosses a milestone threshold (10, 50, 100, 500)
  **When** the connection is confirmed
  **Then** I receive a congratulatory in-app notification: "You now have [N] moots — your network is growing!"

- **Given** I receive a milestone notification
  **When** I tap it
  **Then** I am taken to my network overview showing degree distribution (1st–4th)

## Notes
Milestones are one-time; the same threshold does not re-trigger if the user loses and regains moots past it.

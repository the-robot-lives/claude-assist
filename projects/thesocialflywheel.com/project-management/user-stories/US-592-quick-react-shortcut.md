# US-592: React Quickly Without Opening the Full Picker

## User Story

**As a** Quiet Consumer
**I want to** a one-tap quick-react shortcut on posts
**So that** I can engage without opening the full picker every time

## Acceptance Criteria

- **Given** I am browsing my feed
  **When** I single-tap the reaction icon
  **Then** my most-used emoji is applied immediately without opening the picker

- **Given** I want a different emoji
  **When** I long-press the reaction icon
  **Then** the full picker opens for selection

## Notes
Default quick-react is a thumbs-up until the user has a reaction history. Quick-react defaults update dynamically based on usage frequency.

# US-109: macOS receivables cockpit

## User Story

**As a** desktop finance power user  
**I want to** use a native macOS receivables cockpit  
**So that** long finance sessions have dense views, keyboard shortcuts, and desktop-native performance

## Acceptance Criteria

- **Given** I open the macOS app  
  **When** I review receivables  
  **Then** I see dashboard metrics, invoice queues, aging buckets, saved filters, and primary actions in a desktop-native layout

## Notes
The macOS app should not be an enlarged mobile app. Use sidebar/detail, toolbar actions, command menus, and keyboard-first patterns.

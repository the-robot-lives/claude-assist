# P-007: Eli Freeman

## Demographics

| Attribute | Value |
|-----------|-------|
| Age | 47 |
| Occupation | Owner-operator with ADHD and dyslexia |
| Location | Portland, OR |
| Tech comfort | medium |

## Bio
Eli manages billing under time pressure and benefits from clear hierarchy, keyboard support, reduced motion, and error prevention. He wants the interface to make the next action obvious without hiding important details.

## Goals
- Complete billing tasks without losing place
- Use keyboard-first workflows for repetitive entry
- Recover easily from mistakes before invoices are sent

## Frustrations
- Dense accounting screens blur together
- Ambiguous errors cause rework
- Animated or overloaded dashboards make focus harder

## Behaviors
- Uses search and keyboard shortcuts
- Prefers saved defaults and inline validation
- Reviews confirmation screens carefully

## Job to Be Done
> "When I am handling billing admin, I want focused flows with clear state and recovery, so I can avoid costly mistakes even on low-focus days."

## Relationship to Product
Edge-case persona anchoring cognitive accessibility, keyboard navigation, validation, and readable financial UI.

## Scenarios
- **Scenario 1:** Create an invoice using keyboard navigation
- **Scenario 2:** Recover from a validation error without losing entered data

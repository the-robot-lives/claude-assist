# P-009: Victor Han

## Demographics

| Attribute | Value |
|-----------|-------|
| Age | 46 |
| Occupation | Finance operations lead |
| Location | San Francisco, CA |
| Tech comfort | high |

## Bio
Victor spends long sessions reconciling payments, reviewing aging reports, and cleaning invoice exceptions. He wants a desktop-native macOS app with keyboard shortcuts, multiple windows, persistent filters, and dense but readable financial views.

## Goals
- Work across invoices, customers, payments, and reports without losing context
- Keep receivables status visible while using other tools
- Use keyboard-first workflows for repetitive finance operations

## Frustrations
- Browser tabs mix billing work with unrelated admin tasks
- Single-window web apps make side-by-side reconciliation slower
- Finance tools often bury power-user shortcuts and batch operations

## Behaviors
- Opens multiple records side by side
- Uses saved filters, keyboard shortcuts, and exports daily
- Watches receivables status while doing email and bookkeeping work

## Job to Be Done
> "When I am reconciling billing work on desktop, I want a native macOS cockpit with multi-window workflows, so I can move faster without sacrificing auditability."

## Relationship to Product
Victor anchors the macOS app scope: multi-window workbench, menu bar status, keyboard commands, desktop notifications, and dense reporting.

## Scenarios
- **Scenario 1:** Reconcile payments in one window while reviewing invoice history in another
- **Scenario 2:** Open menu bar receivables status before deciding which account to follow up

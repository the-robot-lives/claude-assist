# US-037 — Share a live model view by link

**As** Priya, the tech lead,
**I want** share a link that opens the current live model view for my team,
**so that** we argue about the real system instead of whether a diagram is stale.

## Acceptance criteria
- [ ] Sharing produces a link that opens the model at the same framing, filters, and selection
- [ ] The shared view reflects the current model state, not a frozen image
- [ ] Opening the link requires no per-user setup ritual beyond access
- [ ] A link to a model the recipient can't access shows a clear access error, not a blank load

## Notes
Counters Priya's frustration 2 (no common trusted artifact) and churn condition (can't easily share).

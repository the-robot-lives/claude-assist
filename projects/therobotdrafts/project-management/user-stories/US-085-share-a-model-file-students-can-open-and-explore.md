# US-085 — Share a model file students can open and explore

**As** Elena, the CS educator,
**I want** hand students a model file they can open and explore on their own,
**so that** they learn by doing in a lab exercise.

## Acceptance criteria
- [ ] A model exports to a self-contained file students can open in the tool
- [ ] Opening the file reproduces the same structure and labels for every student
- [ ] Students can navigate, focus, and project but the shared example isn't accidentally mutated
- [ ] Opening a file built on a newer version warns about compatibility instead of failing opaquely

## Notes
Serves Elena's lab-exercise scenario (P-007 scenario 2) and goal 3 (learn by doing).

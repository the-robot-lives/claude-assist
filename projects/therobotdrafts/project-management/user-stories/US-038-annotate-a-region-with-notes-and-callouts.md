# US-038 — Annotate a region with notes and callouts

**As** Priya, the tech lead,
**I want** attach notes and callouts to a tangled region of the model,
**so that** I can mark up the problem areas I want the team to look at.

## Acceptance criteria
- [ ] Annotations anchor to elements or regions and travel with them as the view changes
- [ ] Each annotation has author and text and is visually distinct from model labels
- [ ] Annotations can be shown/hidden as a layer so they don't clutter exploration
- [ ] An annotation on a removed element becomes orphaned-but-visible with a note, not silently deleted

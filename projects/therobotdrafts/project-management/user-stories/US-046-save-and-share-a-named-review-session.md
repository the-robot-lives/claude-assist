# US-046 — Save and share a named review session

**As** Priya, the tech lead,
**I want** save a named review session that reopens to the same view, filters, and annotations,
**so that** everyone in a recurring review lands on the same picture.

## Acceptance criteria
- [ ] A review session bundles framing, filters, highlights, and annotations under a name
- [ ] Reopening or sharing the session restores all of those for every participant
- [ ] Sessions are listed and re-openable across app restarts
- [ ] Opening a session against a changed model resolves elements where possible and notes what moved

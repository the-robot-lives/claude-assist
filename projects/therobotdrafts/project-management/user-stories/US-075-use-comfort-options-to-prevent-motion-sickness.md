# US-075 — Use comfort options to prevent motion sickness

**As** Aiko, the VR/XR power user,
**I want** turn on comfort options like a motion vignette, snap-turn, and hand-locked menus,
**so that** I can use the tool for long sessions without nausea.

## Acceptance criteria
- [ ] A comfort vignette narrows the FOV during locomotion and can be tuned or disabled
- [ ] Snap-turn and smooth-turn are both available with adjustable increments
- [ ] Menus are hand/head-relative, never world-locked, to avoid vection from optic flow
- [ ] Large camera jumps are replaced with comfort transitions (fade/teleport) the user can configure

## Notes
Counters Aiko's frustration 3 (sickness from world-locked menus and big jumps); feasibility F2.

# US-082 — Render projector-legible high-contrast labels

**As** Elena, the CS educator,
**I want** make labels and notation render at high contrast and size for a projector,
**so that** the back row can read the diagram.

## Acceptance criteria
- [ ] A presentation/projector profile increases label size, weight, and contrast
- [ ] Labels stay legible at the zoomed-out LOD used for whole-example views
- [ ] Contrast meets a high-contrast threshold against the background
- [ ] Switching the profile off restores normal density without reload

Counters Elena's non-negotiable projector readability (P-007 behaviors/relationship).

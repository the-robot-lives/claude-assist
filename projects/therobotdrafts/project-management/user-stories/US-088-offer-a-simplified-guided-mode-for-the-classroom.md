# US-088 — Offer a simplified guided mode for the classroom

**As** Elena, the CS educator,
**I want** switch to a simplified mode that hides advanced authoring complexity,
**so that** the tool isn't intimidating to students seeing UML for the first time.

## Acceptance criteria
- [ ] A simple/guided mode reduces the verb set and panels to the essentials (view, focus, project)
- [ ] Advanced features (codegen, interchange, overlays) are hidden but re-enableable
- [ ] The mode is sticky per profile so a class session stays simple
- [ ] Switching back to full mode restores all features without losing the current document

## Notes
Counters Elena's frustration 3 (tools too complex for a classroom) and gentle-learning-curve value.

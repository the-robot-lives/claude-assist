# US-055 — Annotate findings on nodes that persist

**As** Sven, the reverse engineer,
**I want** annotate nodes with my findings and have them persist across sessions,
**so that** my mental map stops evaporating between sessions.

## Acceptance criteria
- [ ] A node can carry a persistent finding note with text and a severity/tag
- [ ] Annotated nodes are badged so flagged elements are findable at a glance
- [ ] Findings persist with the saved model and survive re-import where the node still resolves
- [ ] A finding on a node that disappears on re-import is preserved as orphaned with its original context

## Notes
Counters Sven's behavior of mental maps evaporating and external-notes annotation (P-004 behaviors).

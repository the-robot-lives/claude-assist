# US-039 — Highlight cycles for a review presentation

**As** Priya, the tech lead,
**I want** highlight detected dependency cycles and keep them highlighted while I present,
**so that** I can show the team why a refactor is needed with a clear visual.

## Acceptance criteria
- [ ] Detected cycles can be pinned as a persistent highlight during a session
- [ ] Pinned highlights use the reserved state channel plus shape so they read in monochrome and on a projector
- [ ] I can step between multiple highlighted cycles one at a time
- [ ] Clearing highlights returns to the normal view in one action

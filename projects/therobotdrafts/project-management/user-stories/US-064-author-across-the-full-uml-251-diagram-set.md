# US-064 — Author across the full UML 2.5.1 diagram set

**As** Robert, the enterprise UML modeler,
**I want** create and project all 14 UML 2.5.1 diagram types, not a toy subset,
**so that** the tool meets the coverage my process demands.

## Acceptance criteria
- [ ] All 14 UML 2.5.1 diagram types are available as projection/authoring targets
- [ ] Each diagram type renders the standard notation for its element and relationship kinds
- [ ] A region can be projected to any applicable diagram type and back to the model consistently
- [ ] Selecting a diagram type that doesn't apply to a region explains why instead of rendering an empty diagram

# US-040 — Enter a clean presentation mode for screensharing

**As** Priya, the tech lead,
**I want** switch to a clean presentation mode that hides editing chrome,
**so that** I can screenshare a legible model to a mixed technical/non-technical audience.

## Acceptance criteria
- [ ] Presentation mode hides the verb rail, palette, and dev chrome, keeping the model and breadcrumb
- [ ] Labels and contrast are tuned for projector/screenshare legibility
- [ ] Navigation (focus, drill, orbit) still works in presentation mode
- [ ] Exiting presentation mode restores the full authoring UI exactly as it was

## Notes
Serves Priya's mixed-audience communication goal (P-003 goal 2) and projector legibility.

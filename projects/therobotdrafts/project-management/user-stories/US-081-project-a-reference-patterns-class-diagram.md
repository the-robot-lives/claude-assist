# US-081 — Project a reference pattern's class diagram

**As** Elena, the CS educator,
**I want** import a small reference implementation of a design pattern and project its class diagram,
**so that** I can show students how the pattern maps onto real code, live.

## Acceptance criteria
- [ ] Importing a small project and projecting yields a clean UML class diagram of the pattern
- [ ] The diagram shows the pattern's roles (classes, interfaces, relationships) clearly
- [ ] I can hide noise (helper members) to keep the teaching example focused
- [ ] Projecting a project too large to be a clean example warns and suggests narrowing the region

## Notes
Serves Elena's pattern-lecture scenario (P-007 scenario 1) and goal 1 (show UML mapping live).

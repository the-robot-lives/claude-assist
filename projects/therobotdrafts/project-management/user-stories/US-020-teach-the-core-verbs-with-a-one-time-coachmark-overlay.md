# US-020 — Teach the core verbs with a one-time coachmark overlay

**As** Marcus, the newly-onboarding engineer,
**I want** see a short one-time coachmark overlay walking through Add, Connect, Import code, and Generate,
**so that** I learn the app's core moves without reading a manual.

## Acceptance criteria
- [ ] A first-run overlay highlights each core verb in sequence with a one-line explanation
- [ ] Each step points at the real on-screen control (verb rail), not a generic illustration
- [ ] The overlay can be dismissed at any step and re-opened later from Help
- [ ] It shows only once by default and never re-appears unless explicitly reset

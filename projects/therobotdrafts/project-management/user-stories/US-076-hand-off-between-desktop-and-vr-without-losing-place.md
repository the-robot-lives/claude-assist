# US-076 — Hand off between desktop and VR without losing place

**As** Aiko, the VR/XR power user,
**I want** start a diagram on desktop and pick it up in VR (and back) without losing my place,
**so that** I can move fluidly between modalities on the same work.

## Acceptance criteria
- [ ] Switching to VR opens the same model at an equivalent framing and selection
- [ ] Edits made in either modality are immediately present in the other (same underlying model)
- [ ] In-progress authoring state (active verb, sticky mode) carries over sensibly or resets cleanly, never strands
- [ ] If a headset isn't connected, the VR action explains that instead of failing silently

## Notes
Serves Aiko's parity-check scenario (P-006 scenario 2) and goal 3 (switch fluidly).

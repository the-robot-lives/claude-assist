# Elena Vasquez — CS Educator / Trainer

## Demographics

| Field | Value |
|-------|-------|
| **Age** | 35-50 |
| **Role** | Senior Lecturer, Software Design |
| **Technical Level** | Advanced |
| **Industry** | Higher education / corporate training |
| **Location** | Madrid, hybrid teaching |

## Bio

Elena teaches software design and design patterns to students who have never seen a system bigger than a class assignment. She wants to show, not tell, how real systems are shaped and how UML maps onto actual code. Her diagrams have to be correct, clear, and legible on a projector.

## Goals

1. Show students how UML notations map onto real code, live
2. Build clean teaching examples that project clearly to a class
3. Let students explore a model to learn by doing

## Frustrations

1. Static slides make UML feel like bureaucracy, not understanding
2. Hand-drawn examples don't connect to real code
3. Tools are too complex or too expensive for a classroom

## Behaviors

- Builds canonical example diagrams each term
- Projects to a screen; readability is non-negotiable
- Assigns exploration exercises

## Job to Be Done

> "When I teach software structure, I want to show the same system as code and as a navigable model side by side, so students grasp the connection instead of memorizing notation."

## Relationship to Product

Elena is an education user. She values diagram coverage, clean projection/export, legibility, monochrome-safe visuals, and a gentle learning curve. She churns if the tool is intimidating or the diagrams don't read on a projector.

## Scenarios

1. **Pattern lecture** — Elena imports a small reference implementation of a design pattern and projects its class diagram to walk through it.
2. **Lab exercise** — Students get a model file and explore it to answer questions about the system's structure.

# Node-type icons & 3-D forms

Visual assets for every `ElementKind` (see `Assets/Scripts/Authoring/Model/Kinds.cs`), across both of the
tool's registers (`docs/specs/design-conventions.md §0`): the flat **2-D projection/palette** icons and the
**3-D bubble-view** meshes.

## 2-D icons — `Nodes/*.svg` (144 files)

Filled-hue notation silhouettes, one per kind, in the kind's `KindInfo.Hue` with a darker outline and
luminance-aware interior detail (white on saturated fills, dark ink on pale fills). These are the 2-D
register — palette entries, legends, projected-diagram glyphs.

- Regenerate: `python3 tools/gen_node_icons.py Assets/Icons`
- Review: open `_contact-sheet.html` (groups all 144 by diagram family).

## 3-D meshes — the live renderer

The real 3-D nodes are procedural meshes built by `Uml3DNodeShape.Build(kind, w, h, d)`
(`Assets/Scripts/Uml3D/Shapes/`), tinted by hue, drawn by `UmlNode3D` in `Uml3DScene`. Previously ~110 of
144 kinds fell back to an identical box slab; they now get distinct silhouettes:

- New silhouettes live in `Uml3DShape_Ext.cs` — pentagon (send-signal), accept-event notch, hexagon,
  chevron, stadium, disc, deep 3-D box, thin **bar** (fork/join · activation · ports), **sphere** /
  flattened sphere (function · field, per §1.1), **clipped-top** (DMN BKM), **rounded-bottom**
  (deliverable), **layered slabs** (plateau) — wired into `Uml3DNodeShape.Build`, plus rounded-rect tiles
  for the software-system / container / capability / service family.
- Kinds given a non-rectangular silhouette also take a centered-label face (`Face()` → `NameOnly`) so a
  rectangular card can't spill past the outline.
- Genuinely rectangular kinds (class/interface/enum/table, most SysML/EA rectangles) stay boxes — that is
  their correct UML notation; they're differentiated by hue + the front-face compartments/EA glyph.

### Render the real per-kind 3-D gallery

`Assets/Editor/Uml3DIconBaker.cs` renders each kind's actual engine mesh (lit, 3/4 view) to
`Assets/Icons/Nodes3D/*.png`. Run from a **case-insensitive** checkout (Unity refuses case-sensitive
volumes):

```
Unity -batchmode -projectPath . \
  -executeMethod TheRobotDraft.EditorTools.Uml3DIconBaker.BakeAll -quit -logFile Logs/bake.log
```

or in the editor: **Tools ▸ Robot Draft ▸ Bake 3D Node Gallery**.

### Offline preview — `_3d-forms-preview.svg` / `.png`

An oblique-extruded approximation of the distinct 3-D forms (generated by `tools/gen_3d_preview.py`), for
when Unity can't run. It shows the *shapes*, not the true lit engine render — use the baker above for that.

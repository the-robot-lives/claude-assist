# US-21 — Full-screen Prototype Player

**As** the UX researcher / PM (`ux-researcher-pm`)
**I want** to run the FSM-driven interactive prototype full-screen with API/LLM/key-value wiring live,
**so that** I can put a realistic, shareable experience in front of a participant.

**Priority:** P1  **Size:** M

## Acceptance criteria
- The Prototype Player runs the current prototype full-screen, free of editor chrome.
- FSM transitions, API/webhook calls, LLM calls, and key-value state all execute live.
- The run renders at the configured fidelity (high-fi where set).
- A shareable link launches the player for a participant.
- State can be reset to the initial state for a fresh session.

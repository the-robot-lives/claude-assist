# US-22 — Screens / project dashboard

**As** the agency consultant (`agency-consultant-demos`)
**I want** a gallery of the screens in a project showing fidelity status and export readiness,
**so that** I can manage many screens and client variants and see at a glance what's demo- or ship-ready.

**Priority:** P1  **Size:** S

## Acceptance criteria
- The dashboard lists all screens in a project with thumbnails/labels.
- Each screen shows its fidelity status (low-fi / high-fi / mixed).
- Each screen shows export readiness (e.g. has theme, has upverts, exportable).
- I can open a screen into the Editor or launch it in the Prototype Player from the dashboard.
- Screens can be organized/labeled to keep variants distinguishable.

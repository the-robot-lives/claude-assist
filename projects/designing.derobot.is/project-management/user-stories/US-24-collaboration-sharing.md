# US-24 — Collaboration and prototype sharing

**As** the agency consultant (`agency-consultant-demos`)
**I want** to share a prototype/project with clients and teammates via a link with appropriate access,
**so that** stakeholders can view or run the demo without me deploying anything.

**Priority:** P2  **Size:** M

## Acceptance criteria
- A project or screen can be shared via a link with a defined access level (view / run / edit).
- A shared viewer can launch the Prototype Player without editor access.
- Access can be revoked and links expired.
- Multiple collaborators see a consistent, current version of the artifact.
- Human-in-the-loop sharing coexists with MCP/agent operation on the same artifact.

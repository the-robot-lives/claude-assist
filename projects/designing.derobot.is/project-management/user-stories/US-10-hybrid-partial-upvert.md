# US-10 — Hybrid partial upvert of a subset

**As** the product designer (`figma-product-designer`)
**I want** to upvert only a selected subset or group of elements on a page while the rest stays in plain text,
**so that** I raise fidelity exactly where it's needed and nowhere else.

**Priority:** P1  **Size:** M

## Acceptance criteria
- I can select a subset/group of elements and upvert only those.
- Upverted and text elements coexist and render correctly on the same page (hybrid mode).
- Detailed entries can be set on the upverted items without touching the text-form remainder.
- Adding or removing items from the upverted group doesn't disturb unrelated elements.
- The page's text source remains intact for all non-upverted elements.

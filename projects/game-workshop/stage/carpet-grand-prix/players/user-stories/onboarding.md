# Carpet Grand Prix — User Stories: Onboarding & Session (US-034 – US-036)

### US-034: One New Thing at a Time
- **Persona:** New player (general)
- **Category:** Onboarding & Session
- **Priority:** Must
- **Story:** As a new player, I want the first course to teach tilt-to-accelerate with no hazards at all, so that I learn one thing before I learn two.
- **Acceptance Criteria:** The very first course in the Playroom contains zero hazard types (no boost strips, sticky patches, ramps, or open edges) — only rails and grade. Every subsequent course introduces at most one new hazard verb relative to the room's established vocabulary (see `../design/mechanics/difficulty-progression.md`).

### US-035: Instantly Resumable or Abandonable
- **Persona:** P-011 (Maria Rodriguez)
- **Category:** Onboarding & Session
- **Priority:** Must
- **Story:** As Maria, I want a run to be resumable or abandonable instantly when my stop arrives, so that the game never holds me hostage.
- **Acceptance Criteria:** Backgrounding or quitting the app during a run costs at most the in-progress run's time — no confirmation dialog, no penalty beyond a missed medal, and no forced completion screen blocks the app from closing.

### US-036: Free Demo Before Purchase
- **Persona:** P-002 (Sarah Chen)
- **Category:** Onboarding & Session
- **Priority:** Must
- **Story:** As Sarah, I want a free four-course demo before the $4.99 purchase, so that I know the tilt controls work for me before I pay.
- **Acceptance Criteria:** The free demo ships the Playroom's 4 courses and 2 cars with the full, unrestricted tilt system — no feature of the core loop is degraded or time-limited in the demo relative to the paid build.

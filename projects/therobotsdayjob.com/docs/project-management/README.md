# Project Management Artifacts

This folder contains the planning artifacts for `therobotsdayjob.com`:

- `personas/`: product and operator personas
- `user-stories/`: product user stories (MoSCoW prioritized)
- index files for quick import into future planning tools

Use this in the next steps: Personas → Stories → Screens → Components.

## Topline Problem Framing

- Teams need repeatable AI operational work without losing auditability.
- Humans need visibility and override control over delegated work.
- New users need to trust the system quickly using simple first-time setup.

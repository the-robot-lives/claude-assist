# US-001: Bootstrap a robot team in 10 minutes

## User Story

**As a** founder-operator  
**I want to** create a team from a small starter template  
**So that** I can start using the product immediately without custom setup.

## Acceptance Criteria

- **Given** I am on the setup flow, **When** I choose a template, **Then** the system creates 3–5 default robots and workflow links.
- **Given** the team is created, **When** setup completes, **Then** I see a dashboard with each robot role and status.

## Notes
Use templates from three archetypes: support, content, and operations review.

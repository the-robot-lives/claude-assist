# US-014: Keyboard shortcuts for queue actions

## User Story

**As a** part-time operations contributor  
**I want to** approve, reject, and escalate items from keyboard  
**So that** I can work quickly with fewer context switches.

## Acceptance Criteria

- **Given** focus is in the queue, **When** I press standard shortcuts, **Then** actions trigger without modal-only dependencies.
- **Given** an action is triggered, **When** confirmation appears, **Then** I can complete or cancel via keyboard.

foryou signup widget

Drop a signup form on any site with one line. The form's fields come from the List's declared attributes at runtime — change a List's attributes and every embed updates with no code change. All submissions honor the no-leak contract (identical success whether the email is new, already subscribed, or a bot).

Variant A — Script embed (default)

Native feel, themeable, isolated in a Shadow DOM. Submits cross-origin — the host origin must be in the foryou CORS_ORIGINS allowlist. 

<div data-foryou-service="therobotlives"
     data-foryou-list="beta-access"
     data-foryou-theme='{"accent":"#4aedc4","mode":"dark"}'></div>
<script src="https://foryou.therobotlives.com/widget.js" async defer></script>

You can target a List by its globally-unique public slug instead of service+list: 

<div data-foryou-slug="beta-access"></div>
<script src="https://foryou.therobotlives.com/widget.js" async defer></script>

Placeholder attributes

  • data-foryou-service + data-foryou-list — the Service and List slugs.
  • data-foryou-slug — canonical public slug (alternative to service+list).
  • data-foryou-theme — JSON theme overrides (see below). Optional.
  • data-foryou-source — provenance tag stored on the signup. Optional.
  • data-foryou-api — API base override (defaults to the script's origin). Optional.

Variant B — Iframe embed (zero-CORS fallback)

Maximal isolation, no CORS needed (the form posts from within foryou's own origin). Best for sites that disallow third-party script. The iframe auto-reports its height; add the tiny resize listener below (or omit it and set a generous min-height). 

<iframe id="foryou-embed"
        src="https://foryou.therobotlives.com/embed/therobotlives/beta-access?accent=%234aedc4&mode=dark"
        title="Sign up" loading="lazy" scrolling="no"
        style="border:0;width:100%;min-height:220px"></iframe>
<script>
  window.addEventListener("message", function (e) {
    if (e.origin !== "https://foryou.therobotlives.com") return;
    var d = e.data;
    if (d && d.source === "foryou-widget" && d.type === "height") {
      document.getElementById("foryou-embed").style.height = d.height + "px";
    }
  });
</script>

Theme the iframe via query params: ?theme=<url-encoded-json> or flat keys (accent, mode, surface, text, radius, font, …).

postMessage protocol

The embed page posts to window.parent:

{ source: "foryou-widget", type: "height", height: <pixels> }

Always validate event.origin === "https://foryou.therobotlives.com" before acting.

Theme object

{
  "accent":      "#4aedc4",   // primary / button background
  "accentText":  "#05070c",   // button label (auto-clamped for WCAG-AA contrast)
  "surface":     "#0c1018",   // form background
  "text":        "#e6e9ef",   // body text (auto-clamped for WCAG-AA contrast)
  "radius":      "0.6rem",
  "font":        "\"Space Grotesk\", system-ui, sans-serif",
  "mode":        "auto"        // "light" | "dark" | "auto" (follows prefers-color-scheme)
}

Any pair that would drop below WCAG-AA contrast is clamped to a readable value automatically. Omitted keys fall back to the Service's branding, then to foryou defaults.

# 18: Admin Services & Lists

| Field | Value |
|-------|-------|
| ID | SCR-18 |
| Type | dashboard |
| Category | Admin Console |
| User Stories | US-073, US-074 |

## Description
Admin views listing Services with aggregate signup counts and, drilling in, the
Lists per Service with per-list counts and opt-in mode.

## Key Components
- DataTable — Services / Lists with counts
- StatTile — count summaries
- Badge — opt-in mode indicator
- Button — drill into a list

## Interactions
- Browse Services with counts; drill into a Service's lists
- Open a list's signups table; access-scoped rows

## Navigation
- **From:** Admin Console (SCR-17)
- **To:** Admin Signups Table (SCR-19)

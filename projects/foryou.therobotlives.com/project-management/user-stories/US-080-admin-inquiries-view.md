# US-080: Review inquiries in the admin console

## User Story

**As a** site owner/admin
**I want to** review submitted inquiries in the admin console
**So that** I can triage and follow up on leads

## Acceptance Criteria

- **Given** inquiries exist for my sites
  **When** I open the Inquiries view
  **Then** I see each inquiry with submitter, site, fields, and date
- **Given** an inquiry
  **When** I open it
  **Then** I see its full content including enhanced fields (company/project/budget/timeline)
- **Given** many inquiries
  **When** I browse them
  **Then** I can search/filter and paginate

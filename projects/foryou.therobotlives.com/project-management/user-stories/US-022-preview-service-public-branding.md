# US-022: Preview a Service's public appearance

## User Story

**As a** Service editor
**I want to** preview how my Service's public forms look
**So that** I can confirm branding before going live

## Acceptance Criteria

- **Given** I have set Service branding
  **When** I open the preview
  **Then** I see a representative public form with the applied logo and colors
- **Given** I change branding
  **When** I refresh the preview
  **Then** the update is reflected
- **Given** branding is incomplete
  **When** I preview
  **Then** defaults fill the gaps and are clearly indicated

# US-083: Get confirmation that my inquiry was received

## User Story

**As a** person who submitted an inquiry
**I want to** see and/or receive confirmation
**So that** I know my message went through

## Acceptance Criteria

- **Given** I submit an inquiry
  **When** it succeeds
  **Then** I see an on-screen acknowledgment
- **Given** I provided an email
  **When** the inquiry is recorded
  **Then** an acknowledgment email may be sent
- **Given** submission fails
  **When** an error occurs
  **Then** I see a clear failure message and my input is preserved

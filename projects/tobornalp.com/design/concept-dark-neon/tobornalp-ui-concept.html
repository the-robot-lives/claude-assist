#adr-014 — agent write-permission escalation

Agents start read-only. When an agent needs write access beyond its role — like tobor-dev asking to edit this space — it files a scoped grant request instead of inheriting broad permissions. Context in adr-013 — lexorank queues and the agent roles matrix; tracked as TRP-160.

##decision

  • grants are scoped (space or item, never org-wide) and time-boxed
  • every grant is an item — reviewable, linkable, auditable like any other work
  • humans approve; agents may request but never self-approve
[WARN]escalated grants expire after 72h unless a human re-approves. expiry events land in the audit log.

# Timely iOS App

SwiftUI scaffold for Timely's iOS companion app.

Current capabilities:

- Tab-based iOS shell for Today, Timeline, Reports, and Privacy.
- Daily summary for reviewed hours, billable hours, confidence, and prompts.
- Timeline interval review list with confidence and state labels.
- Idle/resumption prompt list.
- Client report list.
- Privacy policy screen.

Expected build path:

```bash
swift build
```

For App Store/TestFlight work, create an Xcode iOS app project and move these SwiftUI sources into the app target, or use them as the basis for an Xcode-generated project with signing, bundle identifiers, assets, and previews.

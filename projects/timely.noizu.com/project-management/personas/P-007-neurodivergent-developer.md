# P-007: Eli Freeman

## Demographics

| Attribute | Value |
|-----------|-------|
| Age | 27 |
| Occupation | Frontend developer |
| Location | Portland, OR |
| Tech comfort | high |

## Bio
Eli does strong technical work but loses context after interruptions and finds heavy administrative workflows exhausting. Timely needs to support correction without shame or cognitive overload.

## Goals
- Resume work with minimal friction
- Correct time from visual context instead of memory
- Avoid noisy prompts

## Frustrations
- Frequent prompts break concentration
- Rigid timers punish focus variability
- Dense dashboards are hard to parse when tired

## Behaviors
- Works in bursts
- Uses keyboard navigation and dark mode
- Benefits from concise visual summaries

## Job to Be Done
> "When I return after an interruption, I want Timely to show what I was doing and suggest the next action, so I can restart without rebuilding context from scratch."

## Relationship to Product
Accessibility-sensitive power user for resumption, keyboard UX, prompt timing, and cognitive load.

## Scenarios
- **First week setup:** Configures projects, capture rules, and privacy defaults before trusting the tool.
- **Weekly review:** Uses timeline evidence to resolve ambiguity and close the week.
- **Exception handling:** Encounters idle gaps, overlap, or sensitive screenshots and needs fast correction.
